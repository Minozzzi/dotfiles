# Binguei independent story validation

1. Setup: `export PATH=$PATH:/Applications/Maestri.app/Contents/Resources`; `maestri note read current-feature` (binding decisions). The qa-checklist note may be .NET-oriented: use repo AGENTS.md. Read `git diff main...BRANCH` fully and the story/plan docs. Do NOT trust Coder reports (/tmp/coder-*.out are claims only).
2. Gates (all must exit 0): `pnpm install --frozen-lockfile`; `pnpm exec turbo run lint typecheck --force`; `pnpm exec eslint scripts && pnpm exec tsc -p scripts/tsconfig.json`; `pnpm format`; `pnpm test:scripts`; `pnpm test` (repeat 2-3x if flakiness is in question); `pnpm quality:coverage`; `pnpm quality:duplication`; `pnpm quality:gate`; `pnpm security:audit`; `pnpm exec turbo run build --force`; `pnpm api:sync` then `git status --short` must be clean; `pnpm api:compat`; `pnpm smoke:container` and `--scenario=NAME`. Check `git diff main...BRANCH --name-only | grep -Ei 'config|threshold|baseline|jscpd|vitest|quality|security|.github'` for relaxed policies. For openapi, count removed lines: `git diff main...BRANCH -- packages/contracts/openapi.json | grep -c '^-[^-]'`.
3. Throwaway E2E: write `apps/api/src/tests/qaN-tmp.integration.test.ts` using createApiFixture (api.room/join/round/command/organizer/state/prisma, baseUrl) and socket helpers in `modules/realtime/tests/helpers/socket-client.ts` (connectPlayer/connectOrganizer/open). Run with `node scripts/testing/with-test-services.ts pnpm --filter @binguei/api exec vitest run FILE`; console.log is swallowed, so `appendFileSync('/tmp/qaN-emit.txt', ...)`. Cover status matrix (401/403/404/400/409), no writes/emits on refusals, leak check for token/ids/cookies, dedupe/concurrency.
4. Mutation: `git worktree add --detach /tmp/binguei-mut BRANCH`, `pnpm install --frozen-lockfile`, `cp` .env from main checkout, `pnpm db:generate`, `pnpm --filter @binguei/db --filter @binguei/contracts build`. Remove the event-order queue and inject `await new Promise(r=>setTimeout(r,Math.random()*40))` between commit and publish to prove ordering tests have detection power; swap RepeatableRead->ReadCommitted to test snapshot claims.
5. Cleanup: delete temp test files and /tmp outputs, `git worktree remove --force /tmp/binguei-mut && git worktree prune`, confirm `git status --short` is empty. Never edit production code.
6. Report: `timeout 60 maestri ask "Maestro Agent" "$(cat /tmp/report.txt)"` (it returns no output after 60s even when delivered; do not resend) AND repeat the verdict in the final reply: per-item APROVADO/REPROVADO, commands/results, defects with repro and severity, what was NOT verified.
